# Apify Store - размер рынка (замер по API 05.11.2026)

Все цифры - из api.apify.com/v2/store. Метод: полный счёт даёт `total`,
структура - случайная выборка 50 страниц по 200 = 2 379 актёров из 108 672,
экстраполяция по доле. Ниши - кластеризация названий по первым двум значимым
словам (без api/scraper/actor/data/get/find...).

## Сколько всего
- **актёров в сторе: 108 672**
- разработчиков (уникальных аккаунтов): ~34 800; половина имеет ровно 1 актёра
- запусков за 30 дней по всему стору: ~181 млн
- медианный актёр: **21 пользователь за всю жизнь**
- 14,3% актёров не имеют запусков вовсе (~15 500)
- актёров с >=1000 запусков/30д: ~20 400 (18,7%) - это «оплачиваемая полка»

## Сколько ниш
- уникальных ключей названий: 1 666 на 2 379 актёров → в среднем **1,43 актёра на нишу**
- ~59 800 актёров (55%) стоят в своей нише одни
- ниш с >=2 актёрами: ~15 700
- **ниш с >=3 актёрами: ~6 200**
- из них с спросом >=500 запусков/30д: ~5 220
- >=2 000 запусков/30д: ~3 800
- >=10 000 запусков/30д: ~1 880
- >=50 000 запусков/30д: ~412

## Концентрация
Топ 10% актёров держат **84,2%** всех запусков.

## Что это значит для плана
Правило владельца: минимума нет, берём любую нишу, где есть хоть какой-то
спрос - «то тут, то там» и есть масштабирование.
Ёмкость списка целей: ~5 200 ниш с конкурентами и живым спросом; при темпе
3-4 актёра в день это запас на 3-4 года, и мы покроем лишь 20-25% списка за год.
Порядок - по объёму запусков в нише, без отбрасывания мелких.
