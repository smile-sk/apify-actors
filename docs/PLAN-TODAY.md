# План: 5 маленьких ниш, где мы можем встать в топ (05.11.2026)

Логика Стаса: популярность решает в тесных запросах, поэтому вход - длинный хвост
маленьких ниш, где лидер слаб. Пять актёров в день, за неделю ~25, дальше штамповка.

Замер: Store API, 100 актёров на запрос, релевантность проверена по названию и
описанию (иначе в нишу попадает TikTok-скрапер). Колонки: всего релевантных
актёров, запусков за 30 дней по всей нише, лидер (пользователи / запуски),
следующие четыре актёра по запускам.

Отброшено и почему:
- favicon api - лидер 9 пользователей, но 15 497 запусков, и второй игрок 1 059 пользователей: втроём не влезем за день.
- html to markdown - первый актёр apify/rag-web-browser (208 929 пользователей), первое место занято площадкой.
- domain availability - 12 441 запуск у лидера, но поле живое (148/2/76/207/117), шанс ниже остальных пяти.
- rss feed reader - 20 041 запуск у лидера, но второй 193 пользователя: входим, только если первых пяти не хватит.
- cron / yaml / unit converter - по 200-700 запусков, деньги меньше расходов на проверку.

Честная оценка денег: ниша на 2-3 тыс. запусков в месяц при цене $0,005 за событие -
это $10-15/мес, если забрать половину. Пять таких = $50-75/мес. Смысл имеет только
масштаб 100+ ниш; одна ниша из этого списка не замена и не зарплата.

Порядок работы по каждому: боль в отзывах лидера → полигон на класс ошибок →
код → живой прогон → один комплексный QA Оресту → публикация → замер позиции.
