## Что это

Актёр - программа на Python или JS, которая живёт на сервере Apify и запускается по требованию:
из веб-интерфейса, через API или через MCP (прямо из Claude, Cursor, Windsurf). Клиент платит за запуск.

## Деньги

- Apify берёт 20 %, нам 80 % выручки.
- Из нашей доли вычитаются platform costs (CPU, память, прокси, трафик, запись в датасет).
- Пользователи бесплатного плана не приносят ничего - их расходы Apify берёт на себя.
- Если цена не покрывает расходы, убыток актёра обнуляется, но общий счёт не тянет вниз.
