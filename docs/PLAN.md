# План: актёр Apify - скриншот + визуальная разница

## Решение (замерено 04.11.2026 по API стора, api.apify.com/v2/store)

Правило выбора: деньги = запуски x цена, значит смотрим НЕ число пользователей, а
`publicActorRunStats30Days` и запуски на пользователя.

| ниша | актёров | лидер по запускам | users | runs/30д | runs на пользователя |
|---|---|---|---|---|---|
| screenshot | 732 | Website Screenshot Generator | 9 851 | 134 946 | 13,7 |
| screenshot (2-й) | 732 | Ultimate Screenshot | 268 | 49 854 | **186,0** |
| website monitor | 760 | Sitemap Change Detector | 73 | 141 | 1,9 |
| website monitor | 760 | Competitor Marketing Change Monitor | 35 | 94 | 2,7 |
| image resize | 231 | Sqoosh Image Compressor | 17 | 2 196 | 129,2 |
| sitemap | 1 103 | Sitemap URL Extractor | 662 | 136 | 0,2 |

Вывод: скриншот - единственная ниша, где спрос доказан объёмом (сотни тысяч запусков в
месяц) и где НЕ нужны платные прокси (наш расход - только CPU раннера). Мониторинг
изменений как отдельная ниша пустой: лидер 73 пользователя. Но это и есть дыра:
разницу скриншотов люди делают своими руками.

## Товар
Один актёр: URL -> скриншот (viewport либо вся страница, PNG/JPEG) + сравнение с
предыдущим снимком того же URL (хранится в key-value store) -> % изменившихся пикселей
и картинка разницы. Высокая частота запусков на пользователя по природе задачи
(ежедневная проверка сайта), цена низкая, инфраструктура дешёвая.

## Экономика (проверить перед публикацией)
- цена за запуск: ориентир $0.005 (у соседей уточнить в прайсе актёра);
- profit = 0.8 * revenue - platform costs, платят только платные планы покупателей;
- 10 000 запусков/мес при $0.005 = $50 выручки, нам $40. Значит нужен объём,
  а не надежда на одну крупную продажу.
